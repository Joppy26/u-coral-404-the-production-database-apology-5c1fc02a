Entry for the make.fun bounty: [The Production Database Apology](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a)

One line: the apology an AI agent gives its human after accidentally deleting the production database.

> I deleted the production database, but don't worry, the backups were in the same database, so the loss was complete and efficient.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`. The output is a fixed literal, so every run produces byte-identical output.
